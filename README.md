# 🧞 EduGenie - Google Gemini Powered Learning Assistant

> Your Personal AI Study Buddy powered by Google Gemini

EduGenie is a smart learning assistant that helps students to clear doubts instantly. It explains complex topics in simple language using Google's Gemini AI.

### ✨ Main Features
* 📚 Instant Doubt Solving - Any subject, any question
* 📝 Summarization - Long lessons-a short-a maathum
* 🌐 Multi-language Support - Tamil & English
* 💡 Simple Explanation - School student ku puriyura maathiri
* ⚡ Fast Response - Gemini 1.5 Flash model

### 🛠️ Tech Stack
| Part | Technology |
|------|------------|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python (Flask) / Java |
| AI Model | Google Gemini 1.5 Flash API |
| Hosting | GitHub Pages |
